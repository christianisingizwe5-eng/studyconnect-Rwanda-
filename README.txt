STUDYCONNECT RWANDA V3
=======================

This is a browser prototype.

HOW TO START
1. Extract the ZIP.
2. Open index.html in Chrome or Microsoft Edge.
3. Create a Student, Teacher, or Admin demo account.
4. Test the dashboard, courses, assignments, quiz, messages, profile and teacher tools.

IMPORTANT
The prototype stores data in the browser (localStorage). It is NOT yet a real multi-user online service.

NEXT PRODUCTION STEP
Connect authentication + database + file/video storage, then deploy the app online.
